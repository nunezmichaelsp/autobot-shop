# Nimbus — autobot demo shop

Static HTML storefront built end to end by an autonomous development bot,
driven by a governed orchestrator that reads tasks from Jira.

Every page in this repository was written by the bot. Each task became a branch,
a pull request and a merge, with every step recorded in an append-only audit log.

This repository is disposable: it is reset to the `demo-baseline` tag between runs.
